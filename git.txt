# Git Commands Cheat Sheet (Correct Order)

1. **`git init`** → Initialize a new Git repository.

2. **`git config --global user.name "Your Name"`** → Set your Git username (one-time setup).

3. **`git config --global user.email "you@example.com"`** → Set your Git email (one-time setup).

4. **`git config --list`** → View current Git configuration.

5. **`git status`** → Check the current status of your repository.

6. **`git add <filename>`** → Stage a specific file (e.g., **`git add readme`**).

7. **`git add .`** *(or* **`git add ./`***)* → Stage all changed/new files.

8. **`git commit -m "Commit message"`** → Save staged changes as a commit.

9. **`git log`** → View complete commit history.

10. **`git log --oneline`** → View short commit history.

11. **`git checkout <commit-id>`** → View a previous commit (Detached HEAD).

12. **`git checkout main`** *(or* **`git checkout master`***)* → Switch back to a branch.

13. **`git branch`** → List all local branches.

14. **`git branch -M main`** → Rename the current branch to **main**.

15. **`git checkout -b <branch-name>`** → Create and switch to a new branch.

16. **`git switch <branch-name>`** → Switch branches (new Git command).

17. **`git remote add origin <repository-url>`** → Connect local repository to GitHub.

18. **`git remote -v`** → Show connected remote repositories.

19. **`git push -u origin main`** → First push of the main branch to GitHub.

20. **`git push -u origin <branch-name>`** → First push of a new branch.

21. **`git push`** → Push latest commits to GitHub.

22. **`git pull`** → Download and merge the latest changes from GitHub.

23. **`git clone <repository-url>`** → Download an existing GitHub repository.

24. **`git diff`** → View changes before committing.

25. **`git restore --staged <filename>`** → Unstage a staged file.

26. **`git branch -d <branch-name>`** → Delete a local branch.

27. **`git push origin --delete <branch-name>`** → Delete a branch from GitHub.

---

## Daily Git Workflow

**`git status`** → Check changes
**`git add .`** → Stage changes
**`git commit -m "Your message"`** → Save changes
**`git push`** → Upload changes to GitHub
**`git pull`** → Get the latest changes from GitHub

---

## First-Time GitHub Workflow

**`git init`** → Create repository
**`git config --global user.name "Your Name"`** → Set username
**`git config --global user.email "you@example.com"`** → Set email
**`git add .`** → Stage files
**`git commit -m "Initial commit"`** → First commit
**`git branch -M main`** → Rename branch to main
**`git remote add origin <repository-url>`** → Connect GitHub repository
**`git push -u origin main`** → Push project to GitHub
